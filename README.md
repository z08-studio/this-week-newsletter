# This Week In Newsletters

Make good weekly reading easier to find. A handpicked newsletter calendar by **z08 Studio**, built for [thisweeknewsletter.com](https://thisweeknewsletter.com).

Browse 33 newsletters from Monday through Sunday. The next layout, currently in local review, gives each weekday a horizontal row of mint title cards beside a persistent reading pane. Drag or scroll a row, or use its arrows, then select a publication for details and verified past issues. A smaller masthead and tighter spacing keep more reading visible. The public site keeps its previous layout until this candidate is approved for deployment.

[Suggest a newsletter](https://docs.google.com/forms/d/e/1FAIpQLScNKI_gcJOtPcRBZZ4xB-IUREZraY1j6dz1tQyKn3MOBTl4Ag/viewform). Every submission is reviewed manually before inclusion.

The selected design combines an illustrated masthead, DM Sans typography, light mint newsletter slips, a compact reading pane, and the z08 Studio footer. Softer raspberry and forest-green accents distinguish the active day and publication. Short pages place the footer near the viewport bottom; longer pages scroll naturally. See [the calendar reference](docs/design/light-slips-reference.png), [schedule research](docs/newsletter-sources.md), and [maintenance instructions](docs/maintenance.md). The repository is private; the website is intended for public readers.
