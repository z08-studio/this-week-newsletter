# This Week In Newsletters

Make good weekly reading easier to find. A handpicked newsletter calendar by **z08 Studio**, built for [thisweeknewsletter.com](https://thisweeknewsletter.com).

Browse 33 newsletters from Monday through Sunday. Select a weekday for its reading list, then click a mint card or a list entry for publication details and verified past issues. The full calendar uses normal page scrolling, with weekday headings and a compact reading panel that stay in view on suitable desktop screens. On phones and smaller tablets, a weekday picker sits above the daily list.

[Suggest a newsletter](https://docs.google.com/forms/d/e/1FAIpQLScNKI_gcJOtPcRBZZ4xB-IUREZraY1j6dz1tQyKn3MOBTl4Ag/viewform). Every submission is reviewed manually before inclusion.

The selected design combines an illustrated masthead, a weekly calendar with a compact reading panel, and the z08 Studio footer. See [the design reference](docs/design/scroll-reading-reference.png), [schedule research](docs/newsletter-sources.md), and [maintenance instructions](docs/maintenance.md). The repository is private; the website is intended for public readers.
